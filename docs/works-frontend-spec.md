## 非公開カード（NDA案件）仕様

`thumbnail` が空のworks（＝NDA案件：保育園70園・大手通信LPO）は、スクショの代わりに
**フロントで「非公開カード」を描画**する。画像アップロードはしない（microCMS Hobbyは画像API不可）。

- 判定：`thumbnail` が空（未設定）なら非公開カード扱い。
- 構成（見本 `docs/design-assets/nda-nursery.svg` / `nda-telecom.svg` 参照）：
  - 小ラベル「制作実績」
  - **「非公開案件（NDA）」バッジ**：塗りつぶしピル＋🔒鍵アイコン。**パッと見で分かる大きさ**で目立たせる。
  - プロジェクト名＋一行の概要（例：全70園規模／LP改修・チーム参画）
  - 技術スタックのチップ（`techStack` を表示）
  - 偽のスクリーンショットは作らない。明確に「非公開」と分かる意匠にする（NDA遵守の信頼シグナル）。
- 配色・角丸・タイポは工程4で決める最終デザインシステムに合わせる（見本はダーク基調の方向性のみ）。ダークモード対応可。
- CSSで `align-items:center` ＋ 実paddingにより、バッジ内アイコン/テキストを正確に中央揃え（SVG見本のピクセル調整は参考程度）。

## Basic認証デモ（order 80/90/100）

- デモは Basic 認証（ID/PW = `demo`/`demo`）。`overview` 末尾に認証情報を併記済み。
- フロントでは「認証付きデモ」と分かる形で表示（例：リンク近くに ID/PW を表示、または注記）。
- 認証情報はクローラー非通過のため検索インデックスされない（意図どおり）。

- 画像は microCMS メディア（手動アップ）。
